# منصة الدراسات الاجتماعية (Social Studies Platform)

منصة تعليمية متكاملة مصممة لمعلمي الدراسات الاجتماعية، تدعم اللغة العربية بالكامل ونظام التشغيل الليلي (Dark Mode).

## المميزات

*   **لوحة تحكم المعلم**: إدارة كاملة للمحاضرات، رفع الفيديوهات وملفات الـ PDF، وإنشاء الاختبارات.
*   **إدارة الطلاب**: التحكم في فتح وغلق المحاضرات لكل طالب على حدة، ومتابعة درجات الاختبارات.
*   **إحصائيات التفاعل**: متابعة مدة مشاهدة الطلاب للفيديوهات.
*   **واجهة الطالب**: مشاهدة المحاضرات، قراءة الملفات، وحل الاختبارات التفاعلية.
*   **تصميم احترافي**: متوافق تماماً مع أجهزة الأندرويد، الآيفون، والكمبيوتر.

## طريقة الفتح والتشغيل في VS Code (How to open in VS Code)

إذا قمت بتحميل المشروع كملف مضغوط (`.zip`)، اتبع الخطوات التالية:

1.  **فك الضغط**: قم بفك ضغط الملف في مجلد على جهازك.
2.  **فتح VS Code**: افتح برنامج Visual Studio Code.
3.  **فتح المجلد**: من قائمة `File` اختر `Open Folder...` ثم اختر المجلد الذي فككت ضغطه.
4.  **فتح Terminal**: من القائمة العلوية اختر `Terminal` ثم `New Terminal`.
5.  **تثبيت المكتبات**: اكتب الأمر التالي واضغط Enter:
    ```bash
    npm install
    ```
6.  **إعداد قاعدة البيانات**: اكتب الأوامر التالية لإنشاء قاعدة البيانات:
    ```bash
    npx prisma migrate dev --name init
    npx prisma generate
    ```
7.  **إضافة حساب المعلم الافتراضي**:
    ```bash
    node prisma/seed.js
    ```
8.  **بدء التشغيل**: اكتب الأمر التالي لبدء تشغيل الموقع:
    ```bash
    npm run dev
    ```

## إعدادات أحجام الملفات الكبيرة (Large File Uploads)

المنصة مهيأة حالياً لاستقبال ملفات تصل مساحتها إلى **2 جيجابايت**. لتغيير هذا الحد:
1.  افتح ملف `next.config.ts`.
2.  قم بتعديل قيمة `bodySizeLimit` في قسم `serverActions`.

> **ملاحظة هامة**: إذا كنت تستخدم خادماً مثل (Nginx)، ستحتاج أيضاً إلى تعديل إعداد `client_max_body_size` في إعدادات الخادم ليتناسب مع هذا الحجم.
